# Analysis tables

The single data layer the paper is written from. Every table is generated by a script in `Tools/analysis/`. Field definitions are in [`datapackage.json`](datapackage.json), and the cross-checks between tables are in [`CHECKS.md`](CHECKS.md).

| Table | Rows | Unit | Source |
|---|---|---|---|
| `replay.csv` | 2,489 | game-run | Every recorded ARC-AGI-3 action history, replayed on the official engine, against the harness's own record |
| `levels.csv.gz` | 4,336 | level played | Engine replay |
| `actions.csv.gz` | 191,674 | action | Engine replay, with the harness's per-action tokens and wall-clock |
| `turns.csv.gz` | 46,216 | model turn | Transcripts in the run-output zips |
| `calls.csv.gz` | 77,497 | model response | Request logs in the run-output zips (October runs onward) |
| `events.csv.gz` | 191,674 | logged action | Event logs in the run-output zips |

**Outcomes and behaviour come from different sources.**
- **Outcomes** (cleared, actions, game-overs, board change) come from the engine. Every recorded outcome reproduces: see `CHECKS.md` §1.
- **Behaviour** (turns, tokens, tool calls) comes from the logs.

**Joins:**
- `events.action_num` = `actions.action_index` (with `run_id`, `game_run`, `pass`), which links an action to its model turn.
- `turns.analysis_step` = `events.analysis_step` = `calls.analysis_step`.

**Rebuild:**

```bash
python3.12 -I Tools/analysis/replay_tables.py . <environment_files> 2026-Paper-Track/data
```

```bash
python -I Tools/analysis/extract_zip_tables.py . <work_dir> 2026-Paper-Track/data
```

```bash
python -I Tools/analysis/check_tables.py 2026-Paper-Track/data
```

Requirements:
- **Game files:** `<environment_files>` is the official public game folder from the ARC-AGI-3 competition's data page. It is not redistributed here.
- **Engine:** the replay needs Python 3.12 with `arc-agi==0.9.8 arcengine==0.9.3 numpy`.
- **Run outputs:** the extraction reads the run-output zips from the Hugging Face dataset listed in `Documentation/DATASET-MANIFEST.csv`.
